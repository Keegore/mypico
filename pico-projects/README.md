# Pico Projects

A collection of Raspberry Pi Pico MicroPython projects and shared helper modules.

## Structure

- `projects/timer-keypad-buzzer/` - Timer project scaffold for keypad, buzzer, and OLED display experiments.
- `projects/blink-test/` - Basic LED blink test scaffold.
- `projects/temp-display/` - Temperature display project scaffold.
- `shared/` - Reusable helper modules for buzzers, displays, and keypads.
